# 报告核查说明

报告生成成功、执行步骤有产物、数值在来源片段中出现，是不同于内容验收的状态。

## 引用

正文的编号引用必须有唯一、明确的URL定义。只有机构名称或主题、不含URL，或同一编号指向多个URL时，显示“未解析”，不会改为链接搜索结果的第N条。引用链接存在也不表示该网页支持正文断言。

## 数字与语义

“数值匹配”只说明某个数值在来源标题/片段中出现。它不证明主体、指标、币种、统计期、分母、否定条件或预测属性相同。报告保持“待人工核查”，不把该计数称作“已核实断言数”。历史缺少范围标记的计数也不升级为事实通过。

金额支持中文万、亿、万亿与英文thousand、million、billion、trillion的数量级转换。例如949亿美元与USD94.9 billion可匹配。该功能不换算汇率，也不说明两个数值属于同一市场或年份。

## 时效与市场范围

当季度预测的期限早于报告日期、又没有明确历史预测标记时，提示补充预测发布日期、预测期及后续实绩。正文同时涉及模组、DIMM、DRAM原厂或HBM等范围并使用金额/百分比时，提示核对市场定义和分母。

这些规则用于发现风险，不能穷尽隐含时间、同义改写、上下文冲突或完整语义蕴含；没有提示也不表示通过。

## 完成标记

完成契约中的“有产物”表示执行步骤返回了实质输出。报告内容是否正确、引用是否支撑、是否满足截至日期，仍需复核。旧报告重新导出时会使用当前说明，原始历史产物不被覆盖。
