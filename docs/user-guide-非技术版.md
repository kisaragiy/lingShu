# 灵枢 · 使用指引（非技术用户版）

> 给拿到 `LingShu-Setup-0.75.2.exe` 的朋友：照这个顺序做，10 分钟内能用上。
> 卡在任何一步，直接把截图发我。

---

## 一、这是什么

一个**装在你自己电脑上**的 AI 助手。主要干三件事：

| 你想干的事 | 对它说什么 |
|---|---|
| 调研竞品 / 整理卖点 | "帮我调研一下 XX 类目，出个对比报告" |
| 整理资料 / 问答 | 上传 PDF、文档到"知识库"，然后直接问它 |
| 攒一份报告 | 让它搜资料 → 自动写成结构化报告，可下载 |

**和 ChatGPT 的区别**：它会**自己拆任务、并行去查、最后给你一份报告**（不是一问一答）；资料和记录都存在**你自己电脑上**，不会上传到我的或任何第三方服务器（除下面第五节说明的情况）。

---

## 二、安装（3 步）

### 1. 运行安装包

双击 `LingShu-Setup-0.75.2.exe`。

### ⚠️ 2. 如果弹出蓝色的"Windows 已保护你的电脑"

**这是正常的** —— 因为这个程序没有购买微软的数字签名证书（签名证书一年几千块，个人项目没买）。不是病毒。

处理方式：

1. 点弹窗左侧的 **「更多信息」**
2. 再点下方出现的 **「仍要运行」**

> 如果你不放心：这个安装包是我微信直接发给你的原文件，没有经过任何网盘/第三方中转。你可以随时叫我发一份校验码给你核对。

### 3. 解压 / 安装到哪（容易踩）

- 用安装包：跟着向导一路"下一步"即可。
- 用便携压缩包：**解压到桌面或「文档」目录**。
  ⚠️ **不要解压到 `C:\Program Files` 下面** —— 那里没有写入权限，程序需要在自己旁边创建数据目录，会启动失败。


装完桌面会出现 **灵枢** 图标。

---

## 三、首次启动

1. 双击桌面图标（**不会弹黑色的命令行窗口**，直接开界面）
2. 第一次会让你**创建一个管理员账号**（用户名 + 密码，随便设，只存在你电脑上）
3. 登录进去

## 四、配置 AI 模型（二选一）

### 方案 A：我帮你配（推荐）

把安装好的界面截图发我，我远程指导你 2 分钟配好。

### 方案 B：你自己配

界面左侧「设置」→ 填 LLM 配置 → 填 API 地址和密钥 → 点"测试连接"。

> 需要自己申请一个 API key（DeepSeek 官网可申请，充 10 块钱能用很久）。不懂就把这步交给我。

## 五、你的数据去哪了（请一定看）

| 数据 | 存在哪 | 会不会外传 |
|---|---|---|
| 你的账号密码 | 你自己电脑 | 不会 |
| 上传的资料 / 知识库 | 你自己电脑 | **不会出本机**（除非你开了搜索功能） |
| 对话记录 / 报告 | 你自己电脑 | 不会 |
| 你问的问题 | 发给**你自己配置的那个 AI 服务商**（比如 DeepSeek） | 会，这是所有 AI 助手的共同点 |
| 用它"搜索"时 | 搜索关键词会发到搜索引擎 | 会。**别拿它搜涉密/公司内部内容** |

**底线**：涉及公司内部资料、客户名单、合同原文，**别上传**。用公开信息没问题。

**想清空数据**：见第八节。

## 六、三个上手场景（照着试）

**① 竞品调研**
> 说："帮我调研 '便携榨汁杯' 这个类目，对比 5 个主流品牌的卖点和价格，出一份报告"
> 等 2–5 分钟，它会给你一份带来源的报告，可以导出。

**② 资料问答**
> 左侧「知识库」→ 上传你的资料（PDF/Word/txt）→ 回到对话问："根据我上传的资料，XX 是什么"

**③ 写报告**
> "把刚才调研的内容整理成一份 800 字的分析报告，带小标题"

## 七、遇到问题怎么办（重要）

**别自己扛，直接找我。** 我需要知道三件事：

1. **你当时想干什么**（一句话）
2. **实际发生了什么**（截图最好）
3. **能不能再试一次**（重复出现 vs 偶发）

> 菜单 → 设置 → **导出诊断包**，把导出的文件发我，我能直接看到问题出在哪。

**这个项目正在早期，你的每一次"卡住"对我都很有用** —— 不是给我添麻烦。

## 八、卸载 / 清空数据

- **卸载**：Windows 设置 → 应用 → 灵枢 → 卸载
- ⚠️ **注意**：卸载**不会**自动删除你的数据。数据在这个目录：
  `C:\Users\<你的用户名>\.agent-harness`
  想彻底清空，卸载后手动删掉这个文件夹即可。
