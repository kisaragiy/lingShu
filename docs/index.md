## 项目简介

**Agent Harness** 是一个面向 AI Agent 开发者的全流程框架，提供从原型验证到生产部署的一站式解决方案。无论你是构建对话机器人、自动化工作流，还是复杂的多 Agent 协作系统，Agent Harness 都能让你专注于业务逻辑，而非基础设施。

### 核心特性

| 特性 | 说明 |
|------|------|
| 🧩 **模块化架构** | 插件化工具系统，按需加载，灵活扩展 |
| 🚀 **一键启动** | 零配置即可运行，5 分钟上手构建第一个 Agent |
| 🔧 **强大的工具链** | 内置 80+ 工具：浏览器自动化、代码执行、文件操作等 |
| 📊 **内置评测** | 完整的自动化评测系统，量化 Agent 性能指标 |
| 🔐 **安全隔离** | 沙箱执行环境，保障系统安全 |
| 🐳 **容器化部署** | 原生 Docker 支持，一键部署到云端 |
| 📝 **CS Demo 模式** | 客户成功演示场景，快速展示产品价值 |
| 🌐 **REST API** | 完整的 HTTP API，方便集成到现有系统 |

## 这个项目解决什么问题

- **结论可核对**：报告里每条引用带工具名、原始 URL、抓取时间，文末按三态标注核验结果；核不到依据的显式列出而不隐藏 —— 这是项目的核心主张，也是 `scripts/demo_research.py` 一条命令就能验证的东西
- **搜索不依赖单一来源**：DeepSeek 搜索 → SearXNG → Tavily → DuckDuckGo 逐级降级，某一环不可用时记 skip 诊断而不是静默返回空
- **失败不静默**：LLM 不可达 / 报告为空 / 零来源都有明确退出码与告警，不落「看起来能用」的半成品
- **自带 Key（BYOK）**：模型与搜索凭据由使用者提供，密文落盘，界面只报「已配置 / 未配置」
- **单机可跑**：默认只绑 `127.0.0.1`，SQLite + 本地文件，不需要外部数据库

### 明确的边界（避免误用）

- **单进程**：会话 / metrics / 取消 / LLM 缓存都是进程内状态，`HARNESS_WORKERS` 必须为 1，多进程会状态分裂
- **单用户优先**：有 JWT + RBAC 与知识库 collection 隔离，但没有多租户配额/计费（见 `AGENTS.md` ADR-001）
- **需要自备模型与搜索**：不内置任何 LLM 或搜索服务，未配置时接口明确报「后端不可用」

### 适合谁

- 想看清 Supervisor-Worker 编排怎么落到工程上的开发者（含失败路径与退出码契约）
- 需要「结论可回查」的调研场景：宁可标注"未找到强相关依据"，也不给不可核对的漂亮话
