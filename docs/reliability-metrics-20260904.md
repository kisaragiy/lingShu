> 验证目标：熔断触发率（正常 0 误触 / 异常必拦）· 降级成功率 ≥95% · 重试有效提升

## 实测结果

| 场景 | 试次 | 结果 | 判定 |
|---|---|---|---|
| **熔断：正常流**（token 够、输出各异） | 100 runs | **0% 误触** | ✅ 无误伤 |
| **熔断：token 超预算**（喂 200K > 上限 100K） | 50 runs | **100% 触发** | ✅ 耗尽前拦截 |
| **熔断：连续无进展**（同一输出 ×5） | 50 runs | **100% 触发** | ✅ 死循环拦截 |
| **降级：首选 100% 故障** | 100 | **成功率 100%**（fallback 100%） | ✅ >95% |
| **降级：首选 30% 抖动** | 100 | **成功率 100%**（fallback 用 25%） | ✅ >95% |

## 结论
1. **三重熔断实装且可靠**：异常（token 超限 / 死循环）100% 在失控前拦截，正常任务 0% 误伤——Day 1 发现的"只有超时在干活"已彻底修复并量化。
2. **降级成功率 100%**（目标 >95%）：首选故障时降级链无缝接管。
3. **重试有效**：80%→99.5%、50%→85.5%，符合指数退避 ≤3 次的理论期望。
4. 运行耗时 18.3s，可随时重跑：`./.venv/Scripts/python scripts/reliability_metrics.py`
