真实任务主题是根据 Python 官方文档比较 asyncio.to_thread 与 loop.run_in_executor，涉及用途、contextvars 传播和取消行为。归档记录的模型为 deepseek-flash，搜索后端为 DeepSeek；该次 Web 运行记录为 17.0 秒、1 轮，仅代表这一个案例，不是成功率或性能基准。

本轮没有重新执行推理，截图中的界面时间不作为原任务耗时证据。历史消息从已保存的真实会话恢复，正式报告重新渲染；运行在独立的本机数据目录，不含真实模型密钥或其他用户会话。

报告仍需人工核对语义、来源支持关系和完整性。链接存在、报告生成成功或来源数字匹配都不等于断言正确。本组截图只证明界面呈现与该历史输出的存在；工程质量以 [CI 日志](https://github.com/kisaragiy/lingShu/actions/workflows/ci.yml)、测试和可复现代码为依据。

本地复现界面：按主 README 启动服务，点击“新会话”；运行自己的调研任务后，在报告页查看正式报告。截图未把未配置模型的演示实例称为可在线推理的公开服务。
